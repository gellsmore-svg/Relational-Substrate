## Inquiry chosen

Answer two related analytic questions for declared XOR-update systems:

1. When can one invertible binary-linear change of coordinates make every
   distinct event mask a single-coordinate update?
2. When an independent-mask recoding leaves inactive coordinates, when can
   those coordinates be discarded without losing exact first-order Markov
   closure?

Also distinguish failure of binary-linear recoding from failure of arbitrary
injective state encoding by examining the canonical three-mask and four-mask
binary dependence circuits. Neither case is selected by a hoped-for fraction.

The formal class is a finite full bit space, distinct nonzero XOR directions,
one declared event per step, and nonnegative integer current-state weights with
halt self-loop completion. Recoding claims concern every named direction;
kernel-level necessity additionally requires those directions to be enabled.
No event labels, coordinate meanings or physical ontology are assumed preserved.
