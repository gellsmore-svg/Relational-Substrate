## Chosen question

Can finite weighted labelled components compose over a **genuinely identified,
changing port value**, retain a usable boundary for further composition, and
be compared exactly with Cartesian copies? Which transition consistency makes
the agreement set invariant, and when does enforcing agreement change the law?

This changes the valid state space and event admissibility, rather than merely
extending the fixed-H contextual-probe theorem. The interface value may change
on shared events. It is read from constituent states and identified across them;
there is no extra independently declared membership/controller coordinate.

Use a finite nonempty port set P and fixed handshake alphabet H. Each component
has finite nonempty states, an onto map to P, nonnegative integer event weights
and **positive private events that preserve the port**. Shared events may change
it. Compatible composite states have equal port value; a synchronized event
survives only when the two target ports also agree. Private events interleave.
Only final composed rows normalise; empty rows halt without adding events.
The output inherits the common port, H and the same private-event contract.
Surjectivity makes all typed pairings nonempty and supports reapplication;
it is not a claim that every state/port is reachable.

Investigate the weighted associativity/unit contract, representation as guarded
Cartesian events, and a necessary/sufficient support criterion for agreement
invariance. A failure may show that identification is an additional constraint,
not a harmless restriction of the unconstrained kernel. Equal component port
transition marginals need not be pathwise agreement under product matching.
Do not call an ordinary finite-state encoding a new primitive or ontology.
