# Atlas continuation of RRC

**Status:** active continuation. **Not** a new programme and **not** a replacement of RRC-001.

**Parent charter:** `charter.md`. **Method:** OTR 1.0, same text and hash as the parent.

**Historical round:** RRC-001 remains frozen. Its plan, results, interpretation, and ledger rows are not edited. `docs/rrc-002-proposal.md` stays an unfrozen note. Its analytic leftovers stay open. They are not the atlas agenda.

## Aim

Accumulate a navigable library of elementary relational behaviours. A round is chosen because it covers a new region, supplies a contrast, or separates two representations. A round is not chosen in order to explain the last striking cell.

The product is the library. An ordinary cell is a successful contribution. A null, a cancellation, and a failure of an effective description are recorded beside anything that looks distinctive.

## What this continuation does not try to prove

These remain possible later questions. None is an organising conclusion:

- Six nodes are special.
- Relational complexity has a finite bound.
- Recursive structures must appear.
- More constraints must produce more organisation.
- Constraint interactions must produce novelty.
- Structures must have compact effective descriptions.
- The same rule grammar must survive every change of scale.

## Cycle

Orient, select, freeze, calculate, observe, challenge, integrate, reflect, continue.

Execution stays the RRC-001 cycle: a frozen plan, items of about one to three minutes, a 120-second watchdog, a five-minute hard ceiling, atomic results, resume without repeating verified items. `plans/rrc-001.json` is not a file this continuation edits.

## Two libraries

1. `atlas/ideas.jsonl` — mathematical possibilities, including ones with no experiment yet.
2. `atlas/coverage.jsonl` — which regions are open, frozen, exhaustive, partial, sampled, analytical, or infeasible.
3. Experiment records — one directory per frozen round under `results/`, with a manifest and per-item results.
4. `atlas/equivalences.jsonl` — distinct descriptions with the same mathematical object. The object is named by `equivalence_type` on rows that carry it. A pattern of agreement does not automatically become the next round.
5. `atlas/patterns.jsonl` — cross-experiment relations. A pattern does not automatically become the next round.
6. `atlas/questions.jsonl` — open questions with no duty to close them in the next round.
7. `coherence/findings.jsonl` — the existing ledger. New rows are appended. Old rows stay byte-for-byte.
8. `PROGRESS.md` — the handoff.

## Constraint discipline

The opening grammar is the smallest set of operations that the current single-toggle chain can already represent. Cardinality (how many constraints are declared) and expression complexity (literals per feature, in the Constraint Laboratory's K and J sense) are stored as separate fields.

A constraint is not written to favour a target shape, attractor, or motif. Wedge-forming rules from RRC-001 are not the template for the opening batch.

If a later idea needs history, an independent hyperedge, or a multi-pair event, the compilation gate in `docs/compilation-gate.md` applies first. The atlas records the trade-off or the missing coordinate. It does not rename an existing mechanism.

## Carriers

A carrier is the set of pairs that are allowed to be events. It is not a drawing of a complete graph, and it is not an emergent structure. The state is the subset of the carrier that is currently present. Complete, chain, branch, cycle, and disconnected carriers are different state spaces when their edge sets differ.

## Observation

Each atlas cell reports a common core defined with the cell: support, recurrent classes, declared versus effective cardinality, literal complexity, a hash of the weight table, and a stationary summary only when the stationary law is unique. Equality of a hash is equality of the weight table. Equality of one observable is not dynamical equivalence.

Imposed carriers, designated node labels, and the clock (`halt_self_loop`, one toggle per step) are labelled as instruments.

## Selection balance

After each verified batch, the next batch prefers uncovered coordinates (breadth) unless a specific contrast would separate two representations already in the library (discrimination). A new pattern is registered and left open unless a broader gap in the coverage register is smaller and more informative.
