## Regenerating

```bash
python3 books/v2/tools/build_concept_graph.py      # concept graph, metrics, terms list
python3 books/v2/tools/assemble_manuscript.py      # manuscript from chapters
python3 .claude/skills/human-book-readability/scripts/book_metrics.py \
    books/coherent-biblical-ontology-second-edition.md \
    --terms books/v2/analysis/terms-edition2.json    # readability indicators
python3 books/v2/tools/build_covers.py             # covers (PNG rendering needs cairosvg)
npm run books:epub:v2                              # EPUB 2 build and epubcheck validation
```

Figures and covers are committed as PNG, so the EPUB build needs only `pandoc` and `epubcheck`. Re-rendering the SVGs needs `cairosvg` (for example `pip install cairosvg`).
