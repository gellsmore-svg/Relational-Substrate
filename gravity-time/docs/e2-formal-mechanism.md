# Formal mechanism note: elementary-square affinities of the GT template grammar

*Prompt GT-P005, deliverable 8.*
- *Sections 1–4 were written before the E2A freeze. They are a pure algebraic derivation, checked on synthetic factor tables (a proof-verification fixture; no round cell).*
- *Section 5 is filled after E2A and E2B and is marked as such.*

## 1. Setting and assumptions

| Item | Assumption |
| --- | --- |
| Grammar | Ordinary pair DSL, order 2, label-covariant templates of `gte0a.component_expressions`: close_form, close_dissolve, adj_form, path_form, path_dissolve |
| Rates | W(x, g) = Π over components of m_c^{w_c(x, g)}, applied to formation (g absent in x) or dissolution (g present) according to the component kind. w_c(x, g) is the number of satisfied instances (witnesses) of component c for slot g in state x |
| Factors | m_c > 0 for the identity; components with m_c = 0 are treated in section 3 |
| Witness counts | w_c(x, g) depends only on slots other than g (template conditions never read g itself) |
| Scaffold | HELD fixes the source triangle (its dissolution has rate 0); those slots never toggle. FREE has no scaffold |
| N, start, clock | Any N ≥ 3. The identity is about rates, so it holds in either clock and does not depend on the start or on the recurrence class |
| Square | For distinct slots e and f and a base state x where both are absent: x → x+e → x+e+f → x+f → x, read as "form e, form f, dissolve e, dissolve f". Its log affinity is A = log[W(x,e) W(x+e,f) W(x+e+f,e) W(x+f,f)] − log[W(x,f) W(x+f,e) W(x+e+f,f) W(x+e,e)] |

## 2. The identity

Write Δ_f w_c(·, e) = w_c(x+f, e) − w_c(x, e). This is how much adding f changes e's witness count. Because witness counts never read e itself, it is the same at x and at x+e.

**Lemma 1 (one component).**
- A formation component contributes log m_c · (Δ_e w_c(·, f) − Δ_f w_c(·, e)).
- A dissolution component contributes log m_c · (Δ_f w_c(·, e) − Δ_e w_c(·, f)).

*Proof.* For a formation component, the forward cycle uses its factor at W(x,e) and W(x+e,f); the reverse uses it at W(x,f) and W(x+f,e). Taking logs, the difference is log m · [w(x,e) + w(x+e,f) − w(x,f) − w(x+f,e)] = log m · [Δ_e w(·,f) − Δ_f w(·,e)]. Dissolution is the same with the cycle's dissolve steps, with the opposite sign. ∎

**Lemma 2 (cross-counts).** Let e = (p,q) and f = (p,r) share exactly vertex p.
- **Closure:** Δ_f w(·,e) = Δ_e w(·,f) = [q~r]. The only new witness is the vertex at the far end of the other slot, which needs the edge (q,r).
- **Adjacency:** Δ_f w(·,e) = Δ_e w(·,f) = 1.
- **Path:** Δ_f w(·,e) = |N_x(r) \ {q}| and Δ_e w(·,f) = |N_x(q) \ {r}|.
  - The new witnesses of e created by f are the paths p–r–d with d ∈ N(r), d ∉ {p,q}.
  - f cannot be the (c,d) link of a witness of e, because c, d ∉ {p,q} would exclude p.
  - p ∉ N_x(r), since f is absent in x.

For disjoint slots e = (a,b) and f = (c,d), every component kind gives Δ_f w(·,e) = Δ_e w(·,f):
- closure gives 0;
- adjacency gives 0;
- path gives the number of present edges between {a,b} and {c,d}, which is symmetric.

**Theorem (square affinity).** Under the assumptions of section 1, with all factors positive:
- if e = (p,q) and f = (p,r) share p, then A = σ · (deg_x(r) − deg_x(q));
- if e and f are disjoint, then A = 0.

Here σ = Σ_{path_dissolve c} log m_c − Σ_{path_form c} log m_c.

*Proof.* Combine the lemmas. Closure and adjacency cross-counts are symmetric, so they cancel. For path components, |N_x(r) \ {q}| − |N_x(q) \ {r}| = deg_x(r) − deg_x(q), because the term [q~r] cancels. ∎

**Corollaries.**
1. **Reversibility.** A rule with σ = 0 has zero affinity on every elementary square.
   - When every non-scaffold toggle has positive rate, the class is a subcube. The cycle space of a hypercube graph is generated by its 4-cycles, so Kolmogorov's criterion holds and the chain is reversible.
   - This covers every positive-factor gradient family (GT-F12) and PCOMP (GT-F30). It predicts the same for the untested pair path_form weak_suppress + path_dissolve weak_suppress.
   - For classes restricted by hard components (not subcubes), squares need not generate all cycles, so reversibility needs a separate argument. For a gradient restriction such as EXCL, the restricted Gibbs law satisfies detailed balance directly, because forward and reverse rates are zero together.
2. **Orientation rule.**
   - The cycle that forms the relation to the better-connected far endpoint second and dissolves the relation to the poorer one first is favoured exactly when σ > 0. Its log affinity equals σ times the degree difference.
   - In words: when σ > 0, the relation to the poorer-connected partner is released while the relation to the richer is kept. When σ < 0 it is the reverse.
3. **HELD handover.** Take an attachment/probe square with shared probe p, far endpoints a source vertex s and a probe q.
   - deg_x(s) ≥ 2, because of the two other source vertices.
   - At N=5, deg_x(q) ≤ 2: the only possible neighbours besides p are the other source vertices besides s.
   - So deg(s) − deg(q) ≥ 0, and every such square has the sign of σ. Reversed attachment/probe squares are impossible at HELD N=5 and possible from N=6.
4. **Scope of the E1 invariance.** Every E0B/E1 family has σ = +log 2 (path_form weak_suppress or path_dissolve weak_favour, plus closure). The 30/30 invariance is therefore the case σ > 0 of this identity, *at the level of local rates*. The identity alone does not show that stationary currents follow.

## 3. Hard components (factor 0)

A component with m_c = 0 sets the rate to 0 wherever it reads a witness. A square is *intact* when all eight rates are positive.
- On an intact square, that component reads no witness at any of the four states. That forces its cross-counts to 0, so its contribution is 0, and the identity holds with σ computed over the positive-factor components.
- **Path prohibition** (path_form or path_dissolve with factor 0): an intact square needs deg(r) = deg(q) = 0 among the relevant vertices, so every intact square has A = 0.
- **One-way transitions.** These arise where a transition is admissible and its reverse is not. With one-way transitions, Kolmogorov's criterion fails on cycles that are not elementary squares, or on broken squares. Irreversibility can then exist with zero affinity on every intact square.
  - Synthetic check: FREE N=4 path_form prohibit has irreversible flux 0.12 and 48 one-way transitions, with no intact square carrying affinity.
  - Entropy production is infinite in that case, and `gte0a.reversibility` excludes such pairs from its sum.

## 4. What is not claimed

- **No statement about stationary currents.** The theorem says nothing about how the currents distribute over squares, about aggregated event-order indices, or about frames. Those are E2A observables.
- **No physical statement.** This is ordinary Markov-chain cycle structure (Kolmogorov's criterion, Schnakenberg's cycle decomposition) applied to a declared grammar. It is not a physical arrow, and it is not entropy production in any physical substrate.
- **Not a theorem outside its assumptions.** For example, it does not cover rules reading three-relation conditions beyond the listed templates, history, or directed relations.

## 5. Results after E2A and E2B (written after the rounds)

**5.1 The identity on every executed cell [M, O].** I1 and I2 hold in all 64 executed cells: 46 in E2A and 18 in E2B. Across all four strata the largest residual is about 1e-15. The affinity was recomputed independently from the rule strings with exact fractions, on 120 seeded squares per cell, and agreed to 1e-12 or better. The census is evidence within its coverage; the identity itself is proved in section 2.

**5.2 Aggregated orientation versus σ (empirical, not proved) [O].**
- In every cell with only positive factors and σ ≠ 0, the signs agree: 32 E2A cells and 4 E2B cells (hard closure exclusion with σ < 0). The quantities compared are σ, the partner-frame index and (HELD) the handover index. One E2A cell lies below the 1e-12 reporting floor.
- No proof is offered that the stationary aggregate must take σ's sign. Square-level circulation runs against local affinity on 6–36% of the circulation mass, so a proof would have to work at the level of the whole cycle decomposition.
- **Counterexample when one-way transitions are present.** Take hard path-form prohibition plus path_dissolve weak_suppress (σ = −log 2, FREE N=5). Its partner index is **+0.070**, opposite to σ. The cell's irreversibility comes mostly from 510 one-way transitions, not from intact squares. The σ rule's domain is therefore chains without one-way transitions.

**5.3 Hard adjacency exclusion makes path terms inert (theorem) [M].**
- Under adj_form prohibit from a start with no adjacent pair, forming (a,b) is admissible only when a and b both have no neighbours. Every reachable state is therefore a matching.
- A path witness needs two present edges sharing a vertex, so every path witness count is 0 and every path component's factor is 1.
- So adj_form prohibit combined with any path term gives exactly the same chain as adj_form prohibit alone. That chain is a gradient restriction and reversible.
- Observed: all five such E2B cells per mode have identical laws (flux 8e-16, expected relations 1.54), and strict enabling (60%) without any direction.

**5.4 The held source is a witness (theorem) [M].**
- In HELD, every attachment slot (p,s) has the two-path s–s'–s'' inside the source triangle. Under path_form prohibit no attachment can ever form.
- Every source vertex has neighbours, so under adj_form prohibit no relation touching the source can form.
- In both cases HELD reduces to the probe-only subgraph: two states at N=5, with one probe–probe slot.
- The imposed reference is not neutral to hard rules.

**5.5 One-way transitions under hard path-form prohibition [M, O].**
- Formation of (a,b) is forbidden while a or b is the end of a two-path; dissolution is unrestricted. So the one-way transitions are exactly the **releases** of relations whose re-formation is currently forbidden.
- Observed: 100% of one-way flux is dissolution (FREE N=5), and it is 5.6–7.3% of total flux.
- Orientation: the partner index is +0.108, +0.126 and +0.070 with no soft term, σ > 0 and σ < 0 respectively. Positive means relations to the poorer-connected partner are released and those to the richer partner are kept.
- *Open (GT-Q11):* a derivation of why one-way release takes this orientation. A sketch: a relation whose endpoint becomes the end of a two-path can still be released, but cannot be re-formed while that path persists, and two-paths end more often at well-connected vertices. The sketch has not been turned into a proof.

**5.6 Enabling and passage [O].** The definitions are in the plans; the classification is in `reports/gt-e2-dissolution-analysis.md`.
- Strict enabling exists only where a hard component is present. That is a definitional consequence of the matched-state comparison: soft factors never make a positive rate zero.
- It occurs with no irreversibility (EXCL; hard adjacency exclusion), with σ-following circulation (hard closure exclusion plus a path term), and with one-way release (hard path-form exclusion).
