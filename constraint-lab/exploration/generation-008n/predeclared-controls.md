# Symbolic controls, not execution results

For irreducible finite T and nonempty A, the killed chain Q=T_BB is transient.
Solving (I-Q)G=T_BA gives hitting distributions. The state return kernel is
T_AA+T_AB G; here T_AA=0 by single-toggle edge-count support. Restriction of
stationary pi to A, normalised, is invariant for this embedded hidden chain.
Stationary source-class aggregation therefore preserves nu(C|K=k), without
making the class-return sequence Markov. The block balance proof substitutes
pi_B=pi_A T_AB(I-T_BB)^-1 into the stationary equation for pi_A.

Stationary material triples match H2/Kpi. For a class-conditioned source,
Pr(P0,P1,P2 | C0=c) is the stationary triple joint divided by the common
Pr(C0=c). Summing exactly those triples with K0=K2=k yields identical
two-event first-return pieces: K1 differs by one automatically. No earlier
return is possible. Return lengths are even, so four is the first possible
distinguishing event length, not an expected universal positive effect.

The same stationary adjacent matching gives equality of source-conditioned
first-event labelled material distributions and thus UP/DOWN initial masses.
Kac: under pi conditioned on a recurrent set D, E[tau_D^+]=1/pi(D).
This controls same-class recurrence, not cross-class first passage.

Complement and opposite-pair kernel conjugacies transport stationary starts,
stopping sets and every finite-path sum. Thus return pieces, tails, MFPTs and
committors transport under the corresponding class bijection; complement
swaps UP/DOWN, opposition preserves direction. If ordered competing targets
reverse, q transports to 1-q. Conjugate does not mean identical labelled law.

If a passage functional differs, uniqueness of Kpi among first-order kernels
on exactly (P,h1) matching the full stationary adjacent H1 law excludes that
entire matched class from reproducing both observations. It says nothing
about hidden-state recoding or an H1 kernel matching occupancy alone.
