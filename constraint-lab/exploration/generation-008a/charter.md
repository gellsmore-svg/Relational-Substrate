# Generation 008A charter

Generation 8A is Mode B, open relational exploration. A completed trajectory has no scientific pass or fail. The scientific object is the fully replayable stochastic trajectory.

The repair is sampling, not a new dynamical law. For each visible source graph the execution basis is all 16 raw triad configurations. Symmetry is computed afterwards. `Aut(source graph, constraint system)` is the set of vertex permutations that preserve both the labelled source pair graph and the labelled constraint multiset. That subgroup may describe equivalence among starts. It does not delete a start from the plan.

Generation 8 graph-only orbit labels remain historical. They are analysis metadata on a Generation 8A episode, not seed coordinates.

Ontology, unchanged: N=4, O=3, G=S=H=L=0, independent hypergraph.

Round A0 is the repair palette copied from the committed Generation 8 plans. Later rounds, if opened, are chosen after A0 observations and are frozen before they run. The generation may stop before A2.
