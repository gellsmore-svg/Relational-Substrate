# 3. Work package P0 — Task-relative sufficiency, from first principles

**Primary new mathematical question:** For a declared family of initial source/route rows, target readouts and observation horizons, when does stationary Markovization preserve *all declared observations* even though the projected full process is not Markov and its path law differs?

1. Equality of one eventual stopped target readout, `a Ar(I-P)Mr R=0`.
2. Equality for a subspace or explicitly finite family of source/route rows.
3. Equality for a family of target readouts versus equality only after target aggregation.
4. Equality for one or several fixed event lengths.
5. Equality at **every** finite event length for declared sources/readouts.
6. Equality of all projected paths / strong lumpability (a stronger property, not inferred from items 1–5).

Seek a useful algebraic representation of source-restricted **reachable differences** and readout **unobservable differences**. ```text
