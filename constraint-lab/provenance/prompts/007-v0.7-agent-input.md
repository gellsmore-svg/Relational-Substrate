

# 5. Critical unresolved confound from Review 006

v0.6 preserved nominal weights but not necessarily effective singleton strength.

Example:

```text

```

is active only when the triadic predicate holds.

The condition-erased control:

```text

```

is active everywhere the event itself is admissible.

So the erased control can be dynamically stronger even with the same nominal grade.

Therefore v0.6 does not yet answer:

> **If a lower-order control is calibrated so that its singleton-level effect equals the higher-order singleton effect, is the composed lower-order interaction still as large?**

This is the primary question of v0.7.

# 20. Two-direction vector matching

```text

=
```


```text
D(m)
=

  ((Delta_C_forward(m) - Delta_T_forward) / s_forward)^2
```

Do not tune scales to improve the match.

Find:

```text

```

over a predeclared search domain.
