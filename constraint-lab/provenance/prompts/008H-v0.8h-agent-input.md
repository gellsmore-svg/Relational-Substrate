# Governing conceptual question

Generation 8G showed that, on its existing event support, the ordinary fixed current-state grammar can represent any positive transition row **as a function of the current state**.

That makes the next boundary exact.

A fixed current-state law can say:

```text
for this x
use this future row.
```

But it cannot say simultaneously:

```text
for this same x
use row A if history was HA

and

for this same x
use row B if history was HB
```

unless the representation is augmented.

Generation 8H therefore asks:

> **Can relational history carry predictive structure that is absent from a complete snapshot of the current ordinary relational state?**

The strongest possible first answer is not a large effect.

It is a clean witness:

```text
same process
same start
same event multiset
same event count
same complete present state
different history
different future.
```

That is the purpose of Generation 8H.
