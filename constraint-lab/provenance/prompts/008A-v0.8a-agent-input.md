Generation 8 reduced the 16 triad configurations under:

```text

```

That is valid only when the active dynamics are invariant under those same automorphisms.

For baseline dynamics:




# Governing methodological principle

Generation 8 taught an important lesson twice.

First:

> **Exploration can reveal a more informative structure than the one we expected to find.**

Second:

> **Symmetry reduction is itself a modelling assumption and must respect the dynamics, not merely the visible state.**

Generation 8A therefore takes the safest small-state approach:

```text
execute every raw hidden context
preserve every stochastic path
apply symmetry only after the data exist
```

The question is not:

> Does hidden context pass a routing test?

It is:

> **When all hidden contexts are actually allowed to speak for themselves, what does the relational system do?**
