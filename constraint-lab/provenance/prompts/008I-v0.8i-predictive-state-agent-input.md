# Governing conceptual question

Generation 8H established that history can matter even when the complete ordinary present material state is identical.

Generation 8I asks a subtler question:

> **When we forget detail about the present, what detail about the past must still be remembered?**

The expected progression is not simply:

```text
history present
→
history absent.
```

It may instead be:

```text
exact last relation label
→
structural role of that relation
→
whether it was formed or dissolved
→
nothing at all.
```

That would show that historical information itself has a projection-dependent relational structure.

The goal of Generation 8I is to determine that structure exactly.
