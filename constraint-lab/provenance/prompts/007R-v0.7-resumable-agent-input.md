# 13. Watchdog

Every worker batch must be a child process controlled by the supervisor.

If a batch exceeds 120 seconds:

1. mark timeout;
2. terminate the worker process tree;
3. preserve individually completed atomic items;
4. schedule only unfinished items again;
5. split a multi-item batch into smaller batches;
6. retry;
7. if a single item repeatedly times out, quarantine it and continue unrelated work.

Use a fixed small retry limit, e.g.:

```text
2 retries after first failure
```

No single item may stall the generation indefinitely.
