# 9. Add pair-event-epoch memory

Define a second process.

Observe the pairwise state only when an actual pairwise relation changes.

Skip over all intervening triadic-only events.

Conceptually define stopping times:

```text
τ0 < τ1 < τ2 < ...
```

where each `τi` is a time at which one pairwise relation toggles.

Then define:

```text
Q_i = pairwise state at τ_i
```

and test whether:

```text
P(Q_{i+1} | Q_i)
```

differs from:

```text
P(Q_{i+1} | Q_i, Q_{i-1})
```

under stationary conditions.

Call this something explicit such as:

```text
PAIR_EVENT_EPOCH_MEMORY
```

This distinction is essential.

---

# 10. Why pair-event-epoch memory matters

Suppose the hidden triad changes only the rate at which triad events occur but does not change the conditional law of the next pairwise transition.

Then:

```text
FULL_EVENT_CLOCK_MEMORY > 0
```

may occur while:

```text
PAIR_EVENT_EPOCH_MEMORY = 0.
```

That means the hidden state affects observed waiting/persistence structure but not the sequence of lower-order relational transitions.

Conversely, if:

```text
PAIR_EVENT_EPOCH_MEMORY > 0
```

then the hidden higher-order relation affects the lower-order transition sequence itself.

This is the stronger result.

Calculate both.
