# Governing methodological principle

Generation 8 is not trying to make the model produce a preferred phenomenon.

It is trying to **look carefully at what the relational system actually does**.

The primary object is not:

```text
a scalar metric
```

or:

```text
a binary verdict
```

but:

```text
a replayable stochastic relational history.
```

The laboratory begins with a visible lower-order organisation, varies hidden higher-order context, allows the runtime to evolve, and records the entire path.

Then it asks:

> **What recurrent relational structures appear?**

> **What does hidden context change?**

> **What does it not change?**

> **Which distinctions persist across trajectories?**

> **Which apparently important distinctions wash out?**

> **What new question is suggested by the accumulated observations?**

That is the purpose of Generation 8.

The exploration remains bounded and reproducible.

But the observations are allowed to lead.
