# 11. Minimal two-parameter lower-order control

The one-parameter pair-face control was:

```text
dissolve(e_B) | L(face) => m
```

where:

```text
L(face)
```

is a pairwise `present` or `absent` predicate.

Generation 7B extends this minimally into a **two-level pair-conditioned transition law**.

For one chosen live pair face `f`, define complementary conditions:

```text
L(f)
NOT L(f)
```

For binary pair state this means:

If target polarity is:

```text
present(f)
```

then the complement is:

```text
absent(f)
```

and vice versa.

Define two independent action multipliers:

```text
m_on
m_off
```

such that:

```text
dissolve(e_B) | L(f)     => m_on
dissolve(e_B) | NOT L(f) => m_off
```

Exactly one of the two rules applies in any state where the action event is admissible.

This avoids overlapping-weight ambiguity.
