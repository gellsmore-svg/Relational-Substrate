### Higher-order state space

The independent triadic relation is genuinely independent of the three pairwise relations. At N = 3 there are 3 pair slots, 1 triadic slot, 16 labelled states, and 8 S₃ state orbits.

### Pairwise support

No conditional pairwise support generated by Generation 3 lay outside the searched Generation 1b pairwise grammar. The higher-order contribution discovered is not primarily a new lower-order support.

### Dynamic coupling

The triadic state can change the conditional law of a future pairwise transition. In particular, T→P rules can produce different pairwise jump kernels on the two hidden triadic slices.

### Coarse-grained memory

The full 16-state process remains first-order Markov with H = 0. After hiding the triadic bit, the pairwise process can fail to be first-order Markov. Generation 3 found positive coarse-grained memory for 5,250 of 7,385 canonical sets.

### Independent reference calculation

The external review independently reconstructed `form(0-1) | present(0-1-2) => strong_favour` and obtained coarse-grained memory total variation 27/616, I(T_t ; P_{t+1} | P_t) ≈ 0.02975 bits, and I(P_t ; T_{t+1} | T_t) ≈ 0.00639 bits, matching the Generation 3 report.

### Terminology

The current FULLY_REDUCIBLE label is too strong. A system may have identical conditional pairwise jump kernels on both triadic slices and still produce coarse-grained pairwise memory, because hidden triadic events alter event timing and visible-state persistence. Pair-jump reducibility and coarse-grained temporal behaviour are separate axes.

### Next scientific step

The review agrees that N = 4, O = 3 is the next useful increase. It disagrees with stopping at K ≤ 1. A K ≤ 1 grammar cannot express a triadic condition on a pairwise action, which is the mechanism Generation 3 identified. The next bounded experiment should be N = 4, O = 3, K ≤ 2, cardinality 1, with a K = 1 subset if useful for validation.
