# Research charter

## Purpose

The laboratory accumulates a reproducible catalogue of constraint motifs and the relational behaviours they generate. The working loop is:

```text
explore → observe → infer → compare → update coherence → ask the next question
```

The programme studies a formal system. A theorem inside that system is a theorem about the system. It is a separate act to ask whether the formal system is coherent with the wider Relational Substrate ontology.

## Working premises

These premises are upstream of the laboratory. The experiments do not try to establish them.

1. Reality is designed.
2. The observable creaturely/material runtime is not ontologically exhaustive.
3. The ultimate receiver in the deepest T–C–R sense may be non-material.
4. The non-material realm is not something this computational laboratory can directly access or simulate.
5. The laboratory therefore studies accessible relational/runtime effects and asks what kinds of architecture are coherent with the wider ontology.

The methodology is conditional:

> Assuming the overarching metaphysical frame, what relational runtime architecture follows coherently, and what can we learn by systematically exploring its possible constraint grammar?

A striking simulated trajectory is an observation inside the formal system. It is not an argument of the form “interesting simulated behaviour, therefore Designer.” The Designer premise is already in force. The laboratory is reverse engineering under that premise.

## Three levels

Every written result keeps these levels apart.

| Level | Question it answers |
| --- | --- |
| Observation | What did the formal model or the sampled trajectory do? |
| Inference | What recurring mathematical or relational pattern does that observation suggest? |
| RS / design interpretation | How might that pattern sit inside the wider ontology, under the working premises? |

T–C–R, closure, boundary, admissibility, and the archived physical models (nematic `RP²`, vortons, molecular descriptors, prior closure scores) may be named in the interpretation level after a result exists. They are not primitive objects of the grammar.

## What a constraint is

A constraint is a transformation of relational possibility. It modifies the measure over otherwise possible transitions. Persistence, exclusion, permeability, release, oscillation, fission, fusion, and patterns not yet named are possible consequences. Those words are not encoded as search targets.

The exploratory analogy is:

```text
relational possibility     ≈ alphabet / operating possibility
constraints                ≈ grammar
stochastic transition      ≈ execution semantics
trajectory                 ≈ expression
emergent organisation      ≈ runtime effect
```

The analogy guides questions. It is not an identity the implementation is required to enforce.

## Exhaustion before depth

Each generation declares a coordinate

```text
E(N, A, O, G, S, H, K, L; semantics, W, T, R)
```

and exhausts that cell. “Exhaustive” means every canonical object in the declared grammar was visited, and the coverage manifest counts labelled objects, objects removed by syntax, objects removed by symmetry, and the regions deliberately left unsearched. A Monte Carlo trajectory is a path through a known possibility space when the chain is finite and fully analysed. It is not itself an exhaustive census.

When a neighbouring cell is too large, the laboratory calculates its size, keeps the exact census of the shallower cell, and labels any sample as a sample.

## Neutrality of outcomes

The engine measures transition structure, occupancy, entropy rate, and path shape. Names such as constructive dissolution, boundary inversion, sacrificial persistence, and stochastic self-transformation are available only after a pattern has been observed, and only in the interpretation level. If a generation does not produce a candidate pattern, the report says so and names the smallest extra expressive capacity that would be required to ask the question again.

## Catalogue

The catalogue keeps null grammars, baseline-equivalent grammars, fragile parameters, absorbing deadlocks, and unexpected symmetries together with any distinctive motif. Evaluation, when used, is a vector of separate dimensions (reproducibility, coverage, parameter robustness, symmetry robustness, cross-substrate recurrence, trajectory distinctiveness, interpretability, global-coherence relevance). Those dimensions are not collapsed into a single score.

## Relation to the archive

`archive/pre-constraint-lab-2026-10-03/` preserves the earlier modelling programme. Archival is a historical boundary. It is not a repudiation. The new laboratory begins underneath geometry, particles, and the earlier closure scores. Later generations may use archived constructions as comparison targets.
