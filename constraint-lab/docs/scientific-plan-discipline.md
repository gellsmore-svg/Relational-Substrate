# Scientific plan discipline

Before a scientific plan is frozen, execution tests may validate plumbing,
synthetic fixtures, serialization, canonicalisation and failure handling, but
they should not calculate representative scientific cells from the actual round.
If actual scientific cells must be used for calibration or timing, their exposure
must be declared and the final plan must distinguish pre-observed cells from
genuinely unopened cells.

Generation 8E declared K3-00 as a pre-freeze smoke test, K3-00 and K3-03 in unit
tests, and algebra items in unit tests. Review 008E notes that its external prompt
had already declared the question, formulas, counts, candidate values and
constructions. This policy is a methodological refinement, not a correction of
the E0 scientific results.

For F0, target/comparator specifications, symbolic local formulas, deterministic
80-digit roots, reference multipliers, canonical law fingerprints and counts
are frozen before scientific kernels. The polarity prerequisite is proved from
the baseline state mapping without running F0 kernels. After freeze, full-kernel,
epoch and stationary conjugacy are checked numerically before bridge execution.
Historical or synthetic laws supply timing and propagation tests. Tests of actual
F0 outputs are only invoked after the frozen commit has been pushed.

Execution checks the committed plan bytes and remote ancestry. Durable atomic
law items cache full and epoch kernels by law fingerprint, analysis version and
precision; items have a 120-second watchdog, resumable state and status/heartbeat.
Scientific results never enter plan construction. All tolerances are fixed in
the plan before results. Failures halt the affected analysis for debugging or an
explicit amendment; they do not select a different comparator or target.

## Formal integration and compilation gate (Generation 8G)

Before introducing a new ontology axis, ask:

> Can the proposed new behaviour be compiled into the existing ontology by increasing K, rule cardinality J, or explicit current state?

Declare the preserved state, event support, clock, projection, initial priors,
weight alphabet and K/J budget. If compilation succeeds, record the representation
tradeoff before claiming new dynamical expressivity. If it fails, state an exact
non-compilability witness. Static syntax novelty or aggregate fit is insufficient.
See the formal expressivity boundary and open-problem architecture.

Pure algebraic derivation, parser audit and fixed proof-verification fixtures do
not require an artificial experiment freeze. A genuinely new bounded scientific
search or representation enumeration does: freeze and push its domain, grammar,
work count and tolerances before execution. Generation 8G uses analytic
constructions/lower bounds and opens no G0 computation.
