# Interpretation boundaries

## Inside the formal system

The following are mathematical statements about the Generation 1 kernel, and the tests lock the ones that are theorems of this engine.

- The baseline on `M > 0` toggles is uniform, irreducible, and period 2, with uniform stationary distribution and entropy rate `log2(M)` bits. At `M = 1` the entropy rate is 0.
- Any strictly positive weight list at `N = 2` normalises to the baseline kernel. Soft constraints on a single toggle are observationally null.
- A zero factor is the only Generation 1 operation that changes the support. Positive factors change measures on the same hypercube.
- For a fixed integer grade assignment and any base `r > 1`, the modal toggle set is independent of `r`. Support is independent of `r`. Magnitudes depend on `r`.
- Halt completion is a self-loop used for Markov analysis. It is flagged and is not a relational toggle.

These statements do not, by themselves, say anything about the ontology of reality.

## Inference

An inference says that a pattern in the observations is stable under the variations the cell actually performed: relabelling, the geometric alphabets, the declared horizons. A pattern that appears at one arbitrary factor and disappears at the neighbouring alphabet is reported as parameter-fragile. A pattern that is only a rephrasing of the baseline is reported as baseline-equivalent.

Inferences live in the generation report. They are not written back into motif files. A motif file carries the observed sentence, the coordinate, and an explicit note that inference and speculation are kept in the report. That split is there so a later reader can see the measurement without inheriting a name.

## RS / design interpretation

An interpretation asks whether an inferred pattern is coherent with the working premises in the charter, and with other relational findings, including findings in the archived programme. It may decrease local coherence, decrease global coherence, or leave the question open. It may notice a tension. It does not certify the premises.

Useful questions at this level, after a census exists:

- Does the same abstract motif recur on a second substrate (graph, hypergraph, simplicial complex, a later embedding)?
- Does the motif reduce the number of assumptions needed to describe several behaviours?
- Does it depend on an arbitrary numerical grade?
- Does a higher-order description subsume several lower-order observations?
- Does it illuminate an older RS word — closure, boundary, admissibility, dissolution, transformation, persistence — or does it pull against that word?

A boundary, if the word is used, has to be earned by an operational pattern such as high internal relational persistence together with low cross-cut transition probability. The engine has no object called a boundary.

## Constructive dissolution

The phrase names an interpretive candidate:

```text
organisation
→ pattern completion
→ relation dissolution
→ released possibility
→ reorganisation
```

The rise-then-release path measure is a weak, neutral shadow of the middle of that sequence (occupation rises by at least 2, then falls by at least 1). It is not the sequence itself. The baseline hypercube already produces a large rise-then-release probability. Only the excess over the baseline is evidence of a constraint effect. If a generation’s excesses are small, or are explained entirely by “prohibit some toggles, and the walk is pushed onto the remaining ones”, the report says that the candidate did not appear as a distinct motif, and it names the smallest extra literal that would make the question expressible. The original cell is not retuned afterward.

## Global coherence

A local pattern that is elegant inside one cell and that conflicts with the wider frame is recorded as a tension. A modest pattern that joins several disconnected observations may be the more useful result. The laboratory does not optimise the catalogue for a striking example.
