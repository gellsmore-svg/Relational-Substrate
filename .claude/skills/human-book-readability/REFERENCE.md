# Research reference (condensed)

Full discussion and the reference list: `research/human-book-readability-skill-research-v1.md` in the repository root.

| Finding | Source | How the skill uses it |
| --- | --- | --- |
| Working memory holds about 4 novel chunks | Cowan 2001, *BBS* 24 | interaction threshold in HCL |
| Element interactivity defines intrinsic load | Sweller 2010, *EPR* 22 | the I dimension |
| Novice supports can hurt experts | Kalyuga et al. 2003, *Ed Psych* 38 | reader-profile calibration |
| Comprehension is the quality of the situation model | Kintsch 1988 | judge models, not wording |
| Repairing inference calls improves learning | Britton & Gülgöz 1991, *JEP* 83 | the X dimension and its priority |
| Coherent text helps low-knowledge readers; can under-challenge experts | McNamara et al. 1996, *C&I* 14 | the cohesion target depends on the reader |
| Cohesion indices (referential, causal, situational) | Graesser et al. 2004 (Coh-Metrix) | the overlap and connective proxies |
| Entity transitions model local coherence | Barzilay & Lapata 2008; Grosz et al. 1995 | entity continuity and reference checks |
| Dependency distance drives sentence difficulty | Gibson 1998 | flag long unresolved dependencies |
| Advance organisers aid integration | Ausubel 1960 | one orienting sentence, not a preview list |
| Concept maps support relational learning | Nesbit & Adesope 2006 | diagrams for dependency structures |
| Analogy maps relational structure, and surface features leak | Gentner 1983 | analogies state their limits |
| Spaced re-encounter beats massed repetition | Cepeda et al. 2006 | reactivation reminders after distance |
| Experts underestimate novice difficulty | Camerer et al. 1989; Hinds 1999 | adversarial naive-reader passes |
| Classic formulas are weak; NLP indices better, yet still limited | Benjamin 2012; Crossley et al. 2023 | formulas only as low-level indicators |
| Plain language: find, understand, use, relevant | ISO 24495-1:2023 | orientation and usability checks |

CLT measurement remains contested. Treat every load estimate as editorial judgement.
