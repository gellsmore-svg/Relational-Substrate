# Programme Milestone Synchronisation

This supplements cadence/runbook and AD-0006; it does not weaken warning review.

1. Fetch main, the existing hub PR branch and programme refs/tags. Reuse a valid hub PR; never merge hub files into programme branches.
2. Select closed source commits and verify exact-head CI. Read reports, proof definitions, source priors and limitations. Do not equate completed science with independent scientific review.
3. Audit separate milestone and aggregate deltas; preserve status-only transitions and their source receipts.
4. Prepare source metadata under proposals/source-metadata/: branch, revision, closed milestones, review state and artifacts. Use propose-pin --metadata to hash this whole decision.
5. Apply AD-0006 only to clean descending proposals. Present all warning-bearing decisions together in one named-human checkpoint. Generic continuation, scientific review, synthesis ratification and publication consent are not warning review.
6. While pending, preview-pins validates in a discarded copy and writes only proposals/previews/. Its target map is hypothetical, never a changed canonical pin or updated main.
7. After genuine review, apply-pin moves commit and metadata together. A wrong/abandoned branch is rejected. The approved pin stays authoritative even if a newer unknown branch is discovered.
8. Reconcile proposals with eight dimensions and nine unsummed axes. Keep decisions/histories and old snapshots; no automatic hypothesis acceptance.
9. Generate/check twice, tests, snapshot, explicit round-close, PR update and exact-head CI. A later author instruction may ratify only the displayed recommendations at their stated categories. Do not ratify using the instruction that opened this round.

Audit reports separate tracked-branch staleness from continuation candidates. Candidate discovery is notification only; completion/review is unknown unless an explicitly declared closed milestone matches. Fetching a newer head never approves it.

OTR is versioned by its method artifact, not arbitrary main movement. SC catalogued-only and private HIST publication gates remain unchanged. No research suite or scientific experiment belongs in a synthesis sync.
